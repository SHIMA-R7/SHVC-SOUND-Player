# 最小構成での実機立ち上げ手順

音が出ない原因を切り分けるための、**アンプと12V系を一切使わない**最小構成。
必要なのは Arduino Nano、SHVC-SOUNDモジュール、ジャンパ線、電解コンデンサ1個、アンプ付きスピーカーだけ。

TDA7053A・12V PDトリガー・音量制御・3.5mmジャックは**全部外す**。
これらは「音が出ない」原因になり得る要素なので、まず疑いの対象から消す。
基板が既にできている場合は、TDA7053AをICソケットから抜き、12V電源を繋がずに、
モジュールの音声ピンから直接引き出す。

## 配線一覧(全17本)

### 電源(4本)

| Nano | SHVC-SOUND pin | 備考 |
|---|---|---|
| 5V | 18 (VCC) | |
| 5V | 24 (VS) | **忘れやすい。ここが浮いていると全く動かない** |
| GND | 19 (GND) | |
| GND | 23 (GND) | |

NanoはUSBから給電する。モジュールの消費は100〜200mA程度なのでUSBの500mAで足りる。

### 固定ピン(3本)

| 接続先 | SHVC-SOUND pin | 信号 |
|---|---|---|
| GND | 1 | /CS |
| +5V | 2 | CS |
| +5V | 20 | /MUTE(D10を使わず+5V直結でよい) |

pin 16 (NC) と pin 17 (DCK) は**未接続のまま**。

### バス(13本)

| Nano | SHVC-SOUND pin | 信号 |
|---|---|---|
| D2 | 7 | D0 |
| D3 | 8 | D1 |
| D4 | 9 | D2 |
| D5 | 10 | D3 |
| D6 | 11 | D4 |
| D7 | 12 | D5 |
| D8 | 13 | D6 |
| D9 | 14 | D7 |
| A0 | 3 | A0 |
| A1 | 4 | A1 |
| A2 | 5 | /WR |
| A3 | 6 | /RD |
| A4 | 15 | /RESET |

### 音声出力(最小: モノラルで2本)

```
SHVC-SOUND pin21 (Audio-L) --[+ 10µF電解 -]-- アンプ付きスピーカーの入力(L)
共通GND                     ------------------ アンプ付きスピーカーのGND
```

- コンデンサの**+側をモジュール側**に向ける(出力にDCオフセットが乗っているため直結しない)
- 容量は10µF〜100µFなら何でもよい
- ステレオで聴きたければ pin22 (Audio-R) にも同様にもう1本
- **イヤホン直挿しは避ける**。アンプ付きPCスピーカーか、オーディオIFのライン入力を使う

## 手順

1. 上記の通り配線する(12Vは絶対に繋がない)
2. `SHVC-SOUND_python/hw_selftest/hw_selftest.ino` を Nano に書き込む
3. Arduino IDE のシリアルモニタを **115200bps** で開く
4. 自動でテストが走る。何かキーを送ると再実行

## 結果の読み方

### 全部 [OK] でノイズが鳴る
ハードは完動。音が出ない原因は `spc_play.py` 側にある。

### 全部 [OK] なのに無音
転送も実行も成功しているので、**原因は音声出力側だけ**に絞れる。
コンデンサの極性、スピーカー側の音量、/MUTE(pin20)がHIGHか、を確認する。

### [1] で止まる(port0/port1 が $AA/$BB にならない)
モジュールが起動していない。読めた値で原因が分かる:

| 読めた値 | 疑う所 |
|---|---|
| `$FF` | モジュールが応答していない。VCC(18)とVS(24)**両方**に5Vが来ているか、GND(19,23)が共通か、/CS(1)=GND・CS(2)=+5V か、/RESET(15)がA4に繋がっているか |
| `$00` | データバスがGNDに落ちている。D0-D7(7〜14番)の配線を確認 |
| 毎回違う値 | /RD(A3)か/WR(A2)の配線ミス、または結線が浮いている |

### [2] で止まる
リセットは通るがデータの書き込みが通らない。D0-D7 のどれかが入れ替わっているか浮いている。
A0(3)/A1(4) の配線も確認する。

### [3] で止まる
1ブロック目は通るのに2ブロック目で落ちる = ブロック切り替えのタイミング問題。
配線は概ね正しいので、ジャンパ線を短くする・電源のパスコンを追加する。

### [5] でマーカーが $99 にならない
転送は通ったがジャンプが失敗している。

## よくある落とし穴

- **VS(24番)の繋ぎ忘れ** — VCCだけ繋いで動かない例が多い
- **GNDが共通でない** — Nanoと外部電源を併用する場合は必ずGNDを繋ぐ
- **ジャンパ線が長い** — ブレッドボードで20cm級の線を使うとバスが不安定になる。10cm以下に
- **音声出力の直結** — DCオフセットでスピーカーを傷める。必ずコンデンサを挟む
