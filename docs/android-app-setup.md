# Androidアプリ開発環境の構築(初めての人向け)

SHVC-SOUNDをスマホ単体(USB直結・PC不要)で鳴らすためのAndroidアプリを作ります。
Androidアプリ開発が初めての前提で、環境構築から順番に進めます。

**全体の流れ**
1. Android Studio(開発ツール)をインストールする
2. スマホ側で開発者向け設定を有効にする
3. 空っぽの「Hello World」アプリを実際にスマホで動かしてみる(ここが一番大事な関門)
4. SHVC-SOUND用のコードを組み込む(次のステップ、この文書では扱わない)

3番まで終われば「道具が揃って動く」ことが確認できたことになるので、
そこから先(4番)は別途コードを渡します。

---

## 1. Android Studioのインストール

1. 公式サイトを開く: https://developer.android.com/studio
2. 「Download Android Studio」をクリックし、利用規約に同意してダウンロード
3. ダウンロードした `.exe` を実行し、インストーラの指示に従う
   - 途中の「Install Type」は **Standard** を選ぶ(初期設定のままでOK)
   - SDKコンポーネントのダウンロードが走る(数GB、Wi-Fi推奨、10〜30分程度かかることがある)
4. 初回起動時のセットアップウィザードもそのまま進めて完了させる

**ここで詰まったら**: 途中でHAXM(仮想化支援)のインストールに失敗しても無視してよい。
今回はスマホ実機で動かすのでエミュレータは使わない。

---

## 2. スマホ側の準備(Android)

### 開発者向けオプションを有効にする

1. 設定 → 端末情報(「デバイス情報」等、機種により名称が違う)
2. 「ビルド番号」を**7回連続でタップ**する(「これでデベロッパーになりました」的なメッセージが出る)
3. 設定に「開発者向けオプション」という項目が新しく出現する

### USBデバッグを有効にする

1. 設定 → 開発者向けオプション
2. 「USBデバッグ」をONにする

この設定は、**開発中にPCからアプリを書き込むため**に必要。
(SHVC-SOUND本番運用時はArduinoと直結するので、この設定がなくても
アプリ自体は動くが、開発・更新のたびに毎回必要になるのでONのままでよい)

### 動作確認: PCとスマホをUSBケーブルで繋ぐ

1. 普段使っているUSBケーブルでスマホとPCを繋ぐ
2. スマホ側に「USBデバッグを許可しますか」のようなポップアップが出たら **許可**
3. 「ファイル転送」ではなく特に何も選ばなくてよい(デバッグ用の接続は自動で確立される)

---

## 3. Hello Worldアプリを実機で動かす

ここまでで道具が揃っているか、実際に確認する。

1. Android Studioを起動
2. 「New Project」→ **Empty Views Activity** を選ぶ
   (「Empty Activity」ではなく「Empty **Views** Activity」。Compose版ではない方)
3. 設定:
   - Name: `SHVCSoundPlayer` (何でもよい)
   - Package name: `com.shvcsound.player` (後で渡すコードとパッケージ名を合わせるため、これを推奨)
   - Language: **Kotlin**
   - Minimum SDK: **API 26 (Android 8.0)**
4. 「Finish」を押すとプロジェクトが作られ、裏でGradleの同期(依存関係のダウンロード)が走る
   - 画面下部に進捗バーが出る。初回は数分かかることがある。**エラーが出ずに終わるまで待つ**
5. 上部ツールバーの緑色の▶(Run)ボタンを押す
6. デバイス選択のダイアログが出たら、USBで繋いだスマホを選ぶ
   - もしスマホが一覧に出ない場合: USBケーブルを挿し直す/別のケーブルを試す
     (充電専用ケーブルだとデータ通信できないことがある)
7. スマホの画面に「Hello World!」と表示されたアプリが実際に起動すれば成功

**この時点で「Android Studio → 実機へのビルド・転送」という土台ができています。**
ここまでできたら教えてください。次にSHVC-SOUND再生用のコード一式を渡します。

---

## この後の見通し(次のステップで渡すもの)

- USBシリアル通信ライブラリ(`usb-serial-for-android`)の追加設定
- `.spc`ファイルを解析するコード(Pythonの`spc_play.py`と同じロジック)
- Arduinoへ転送するコード(`spc_uploader.ino`と全く同じ通信手順。ファームウェア側は変更不要)
- 簡単な画面(曲一覧・再生ボタン・音量スライダー)

Arduino側のファームウェアは既に実機で動作確認済みのものをそのまま使うので、
アプリ側さえ正しく動けば、PCなしでスマホ単体での再生が動く見込みです。

ただし、**このAndroidアプリのコードはこの開発環境(Windows・Android SDK無し)では
実際にビルド・実行して確認することができません。** 渡すコードは書けますが、
最終的に動くかどうかはあなたのAndroid Studio環境で確認してもらうことになります。
